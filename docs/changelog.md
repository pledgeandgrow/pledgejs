# Changelog

All notable changes to PledgeStack are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow
[Semantic Versioning](https://semver.org/).

**Versioning.** The 33 framework packages are released together at one version
(a Changesets `fixed` group, see `.changeset/config.json`); `create-pledge-app`
versions independently on its own npm line. Each package also
has its own `packages/<name>/CHANGELOG.md`, generated by Changesets. Pending
changes live as files in `.changeset/`; `pnpm version-packages` folds them into
the changelogs. Versions are plain semver `0.x.y`, published under the
`latest` dist-tag.

The detailed per-goal history of the September 2026 hardening pass is kept in
[production-readiness-log.md](./production-readiness-log.md).

## [0.2.0] - 2026-09-20

First unified release. Every public package is now on the same version.

### Added

- **Publishable package set.** 34 packages are public: `pledgestack` (CLI),
  `create-pledge-app`, `pledgestack-{shared,core,server,client,auth,state,api,a11y,overlay,seo,image,font,mdx,og,sitemap,rss,ws,adapters,privacy,content,deploy,eslint-plugin}`,
  `pledgestack-renderer-{react,vue,solid,svelte}` and
  `pledgestack-bundler-{pledgepack,vite,rollup,rsbuild,turbopack,webpack}`. Each
  has `exports`, `files`, `engines`, `license`, `repository`, `homepage`,
  `bugs`, `publishConfig.access = public`, a README, a LICENSE and a CHANGELOG.
  The two VS Code extensions are private (Marketplace, not npm).
- **Release automation.** `.github/workflows/release.yml` runs the full gate
  (typecheck, lint, build, tests, release check) and then the Changesets action
  (version PR, then `changeset publish`). `pnpm check:release`
  (`scripts/check-release.mjs`) verifies metadata, one shared version, declared
  workspace dependencies, changeset config and — with `--dist` — that every
  `exports` target exists and no built file has an extensionless relative
  import. CI runs it after `pnpm build:packages`.
- **Working ESM builds.** `scripts/bundle-package.mjs` bundles each library with
  esbuild (`tsc` only emits declarations). Previously `tsc` output such as
  `export * from './router'` could not be loaded by Node ESM.
- **Types for `pledgestack`.** The CLI package now ships resolvable
  declarations (`dist/<entry>.d.ts` re-exporting `dist/packages/*`, with
  workspace imports rewritten to relative paths); the `types` conditions
  previously pointed at files that did not exist.
- **Tests** for the renderer adapters (React, Vue, Solid, Svelte), all six
  bundler adapters, `create-pledge-app`, `pledgestack-eslint-plugin`, a11y,
  image, og and overlay, plus regression tests for every fix below.
  Coverage thresholds are enforced in `vitest.config.ts`.
- `pledge init` installs dependencies with the detected package manager.
- Optional `sharp` dev dependency of `pledgestack-server` for PNG rendering.

### Changed

- All public packages moved to `0.2.0` (they ranged from 0.0.1 to 0.2.3).
- The workspace root package is now named `pledgestack-monorepo` (it clashed
  with the CLI's `pledgestack` name in pnpm filters and Changesets).
- `pnpm build:packages` builds every public package in dependency order.
- Vitest and `@vitest/coverage-v8` upgraded to 4.1.11, clearing the two
  moderate advisories (`pnpm audit` reports no known vulnerabilities).
- `docs/changelog.md` is now a real changelog; the old content moved to
  `docs/production-readiness-log.md`.
- `pledge upgrade` compares prerelease versions correctly.
- `createDevtoolsMiddleware()` no longer injects a `<script>` for a
  `/__pledge/devtools` route that nothing serves; pass `{ scriptUrl }` to opt in.
- `SeaOrmDatabase` and `MlModel` validate their configuration at construction.

### Fixed

- **WebAuthn**: user verification (UV flag) is enforced when
  `userVerification: 'required'` (registration and authentication), and
  `verifyRegistrationResponse` stores the real user id on the credential
  (`options.userId`, falling back to the decoded `userHandle`).
- **API rate limiter** buckets are bounded (periodic sweep + hard cap) instead
  of growing with every distinct client key.
- **NoSQL sanitizers** drop `__proto__`, `constructor` and `prototype` keys
  (assigning `__proto__` on a plain object replaced its prototype).
- **Prometheus** exposition quotes and escapes label values and sanitizes names.
- **Open Graph images**: `ImageResponse` is rendered to a real PNG (flexbox
  subset -> SVG -> native addon or `sharp`); without a rasterizer the server
  answers `501` with an actionable message instead of returning serialized JSX
  labelled `image/png`. Function components and fragments are expanded.
- **`pledge init --skip-install`** works (it previously did nothing because
  init never installed); a failing install no longer aborts scaffolding.
- **`pledge upgrade`**: removed the dead codemod path (`minVersion > from` was
  never true); `--skip-codemods` is now an accepted no-op.
- **Bundler HMR**: webpack `reloadAll()` sent Vite's `full-reload` message;
  it now sends the webpack-dev-server `content-changed` message. Remaining
  limits are documented in `docs/limitations.md`.
- **Vue renderer** now emits `window.__PLEDGE_ROUTE__` and hydrates with the
  server's real params (dynamic routes hydrated with empty props).
- **`pledgestack-eslint-plugin`**: file-name rules match Windows paths and no
  longer match names that merely end in `layout.ts` / `page.tsx`
  (`og-layout.ts` was reported as a layout).
- **a11y `extractTranslations`** no longer reports double-quoted calls twice
  or matches the tail of identifiers (`split('a')`).
- **image**: `generateSizesAttr('fixed')` returned `1px`;
  `generateResponsiveSrcSet` mixed formats in one `srcset`; blur placeholders
  are emitted as a quoted, escaped CSS `url()`.
- **overlay DevTools**: `0ms` load/render times are shown (not `-`) and
  Windows file paths are shortened correctly.

### Security

- OG element trees are depth- and node-limited; only inline `data:` images are
  drawn (no SSRF / local file reads); `on*` attributes and external `href`s are
  stripped from SVG input.
- Dependency advisories: no known vulnerabilities (`pnpm audit`).

### Known limitations (see [limitations.md](./limitations.md))

- 13 of the 15 PSX Rust integrations are JavaScript-fallback stubs without a
  compiled crate; Sea-ORM and ML inference require a `driver` / `executor`.
- Native Rust addons are not shipped in the npm packages.
- HMR exists only where the underlying bundler dev server provides it.
- `ImageResponse` supports a flexbox subset, not full Satori/CSS.
